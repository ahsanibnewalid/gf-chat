Administrator sign-in

Sign in with a Firebase account whose UID is listed in the backend ADMIN_UIDS setting.

A new account is not an admin until its UID is added to ADMIN_UIDS in Render.

Authentication providers

Save credentials, then apply them to Firebase Authentication. Provider developer-console setup and callback URLs are also required.

Email verification policy

Verified email is mandatory. The frontend checks verification status and Realtime Database rules reject unverified accounts. This cannot be disabled from this dashboard.

Backend configuration

Set FIREBASE_SERVICE_ACCOUNT_JSON, SECRETS_ENCRYPTION_KEY, ADMIN_UIDS, FIREBASE_PROJECT_ID, FIREBASE_DATABASE_URL and ALLOWED_ORIGINS in Render. Never place service-account keys or provider secrets in this static site.
